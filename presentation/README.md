## 改嵌入的財務 JSON

整份 `business_model.json` 嵌在 `index.html` 的

`<script type="application/json" id="business-model">`

內。改人數、收費、固定成本或 `expected_outputs` 後存檔即可。第 10、11 頁及附錄 A2 共用同一組函式：

```
periodRevenue = n * fee
periodOp = n * (fee - 60) - fixed
twoPeriodRev = (n1 + n2) * fee
twoPeriodOp = (n1 + n2) * (fee - 60) - 2 * fixed
project90 = twoPeriodOp - 4000
```

第二期 0 人仍計該期固定分攤。試堂 $80 不另計收入。中三／中四不同時相加。切級會載入該級預設價與固定成本。
