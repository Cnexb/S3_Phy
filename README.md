# S3 Physics content packs

Teaching files for Uni+ Learning Tools. All-In-One reads `content-packs/` through content-api.

```
content-packs/<chapter>/manifest.json
```

Do not nest packs in `S1/`–`S6/` folders. Topic Symbols live in `content/topics/physics-topics.json`.

See `.cursor/rules/phy-content-packs.mdc`.

node scripts/test-chapter-assets.mjs
