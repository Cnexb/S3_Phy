# Starter kit

Open **this folder** in Cursor: File → Open Folder… → `starter_kit`.

There is one task folder:

```
task_em_induction_interactive_tool/
  SPEM07-electromagnetic-induction-brief.md
  DSE-EM-induction-practice-(QUE).md
  DSE-EM-induction-practice-(ANS).md
  interactive-tool.html    ← you create this
```

Paste the starter prompt from the brief into one Cursor agent. Save the finished tool as `interactive-tool.html` inside `task_em_induction_interactive_tool`.
