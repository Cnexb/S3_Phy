# Full-time Physics tutor — Electromagnetic induction interview

Standalone brief for a second interview. One task: an interactive HTML tool on electromagnetic induction (HKDSE SPEM07). 140 minutes to make it, then a 15 to 20 minute demonstration.

This package is not wired into the S3 Physics hub.

## Open the brief

```bash
node serve.mjs
```

Then open http://localhost:8792

Serve it over http so the demonstration iframe and the English / 繁體中文 switch work. Do not open `index.html` as a file.

## Give the candidate

- This brief in the browser
- The `starter_kit` folder, opened in Cursor (File → Open Folder…)
- One Cursor agent tab

The hand-in is `starter_kit/task_em_induction_interactive_tool/interactive-tool.html`.

The stacked-boxes lab under `demos/` is a different topic. It shows the standard of a tool a student can act on. It is not the task.
