# Boiling Water Energy Lab

Interactive heat / energy lab. Edit files in this folder; `npm run build` syncs them to `public/boiling-water/` and `dist/`.

Open standalone:

- Boiling water: `index.html` or `?mode=powerTime`
- Heating materials: `?mode=heatCapacity`

Use `?lang=zh|en` and `?embed=1` when embedded in the hub.
